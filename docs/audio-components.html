EXTENSION PACK

@axiom01/audio Component Suite

Battle-tested pro-audio and live performance components adhering to the Axiom01 ethos: minimal class density (Dc ≤ 1), pure semantic HTML, and zero BEM.

Installation & Setup

The @axiom01/audio extension pack is distributed via NPM (bundled inside the main axiom01 package) and via our global CDN:

Via NPM

Install the complete package into your project:

npm install axiom01

CSS path: node_modules/axiom01/css/axiom-audio.min.css
JS path: node_modules/axiom01/js/axiom-audio.js

Via CDN

Direct include in HTML for zero-build setups:

<link rel="stylesheet" href="https://sol-roth-media.github.io/axiom01/css/axiom-audio.min.css">
<script src="https://sol-roth-media.github.io/axiom01/js/axiom-audio.js"></script>

For architectural background, monorepo details, and live concert provenance, read the Extensions Architecture Guide → and the Live Concert Case Study →
