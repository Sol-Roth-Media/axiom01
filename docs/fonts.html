How to Use Axifonts

Axifonts are meant to add character and personality to specific sections of your site, like hero banners, large quotes, or distinct headers. They are not recommended for body text.


1. Include the CSS

First, link the axifonts.css file in your document's <head>.

<link rel="stylesheet" href="css/axifonts.css">

2. Apply the Font-Family

Use the `@font-face` names defined in `axifonts.css` (e.g., `'NeoGothic'`, `'ThickCut'`) in your site's stylesheet. Always provide a fallback font family.

.hero h1 {
    font-family: 'NeoGothic', var(--a-font-family-base);
}

Using Other Web Fonts with Axiom01

Axiom01 is designed to be highly customizable. By default, it uses standard system fonts for performance. If you want to use Google Fonts (like Inter or Roboto) or your own custom fonts, you can easily override the CSS variables.

/* Add to your site.css to override Axiom01 defaults */
:root {
    --a-font-family-base: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
    --a-font-family-mono: 'JetBrains Mono', monospace;
}
