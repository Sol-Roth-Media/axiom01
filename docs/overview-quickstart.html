Overview & Quickstart

Axiom01 enforces a strict Semantic Reality. No utility class chaos. No BEM complexity. Just clean HTML.

What is Axiom01?

Axiom01 is a semantic-first UI framework designed to end the Class Density hoarding problem. We enforce a strict rule: One class per root component. No utility classes. No sub-element classes. You write meaningful markup (<article>, <header>, <footer>), and our CSS tokens handle the styling based purely on structure and element order.

79 Components

Everything from semantic buttons to video players. Production-ready, accessible, and customizable.

149 Design Tokens

Colors, spacing, typography, shadows. Change one variable, your entire site transforms immediately.

15.3 KB CSS

Gzipped. Includes every component. Zero dependencies. Production-ready and blisteringly fast.

Why Axiom01 is Different

Most frameworks force you to choose between clean code and beautiful design. Axiom01 gives you both by leaning into native browser rendering algorithms.

Semantic HTML

Write meaningful markup using native elements. Axiom understands your structure without needing helper classes.

One Class Per Component

class="card" instead of class="flex rounded shadow p-6 bg-white". Keep your DOM expressive and readable.

Accessible by Default

WCAG 2.1 AA compliance built-in. Keyboard navigation, focus states, and contrast are all automatic.

Installation

Get Axiom01 running in your project in less than a minute.

Option 1: npm Recommended

Install via npm, yarn, or pnpm for bundler support:

npm install axiom01

Import into your main CSS file:

@import 'axiom01/css/axiom.min.css';
@import 'axiom01/css/axicons.css';

Option 2: CDN

Add directly to your HTML <head> for rapid prototyping:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/axiom01/css/axiom.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/axiom01/css/axicons.css">

<!-- Axicons SVG Injector -->
<script src="https://cdn.jsdelivr.net/npm/axiom01/js/axicons-base.js"></script>
<script src="https://cdn.jsdelivr.net/npm/axiom01/js/render-icons.js"></script>

Recommended Project Structure

Axiom01 expects a separation of concerns between core framework styles and your site-specific overrides. Always keep a custom site.css loaded after Axiom01.

your-project/
├── index.html
├── css/
│   ├── axiom.css       (Core framework)
│   ├── axicons.css     (Icon sizes/animations)
│   └── site.css        (Your overrides and theme variables)
└── js/
    └── app.js

Your First Components

Axiom01 styles standard HTML tags automatically. When you need a specific component, add a single class to the root element.

Layout Grids

Axiom01 handles responsive grid structures mathematically. Use .grid for automatic wrapping columns.

<div class="grid">
  <div class="card">Column 1</div>
  <div class="card">Column 2</div>
  <div class="card">Column 3</div>
</div>

Buttons

Semantic buttons use a single variant class on the native <button> element. For links, add the .button class alongside the variant.

<div class="actions">
  <button class="primary">Save Changes</button>
  <button class="secondary">Cancel</button>
  <button class="outline">Outline</button>
  <button class="ghost">Ghost</button>
</div>

Cards

Structured content containers utilizing native semantic children (<header>, <footer>, <figure>) instead of messy utility wrappers.

<article class="card">
  <header>
    <h4>Feature Card</h4>
  </header>
  <p>Semantic structure for organized content.</p>
  <footer>
    <button class="primary small">Learn More</button>
  </footer>
</article>

Forms

Fully accessible form controls with consistent styling — absolutely zero classes required on inputs or labels.

<form>
  <label for="email">Email Address</label>
  <input type="email" id="email" required>

  <label for="message">Message</label>
  <textarea id="message" rows="3"></textarea>

  <button type="submit" class="primary">Send Message</button>
</form>

Customizing the Theme

CSS Variables for Global Control

Axiom01 is built entirely on CSS Custom Properties (variables). To change the look and feel of the framework, simply override the variables in your site.css file. No Sass or build step required.

/* inside your site.css */
:root {
  /* Change the primary brand color using OKLCH */
  --a-color-primary: oklch(0.6 0.2 250); 
  
  /* Make the global corner radius perfectly round */
  --a-radius-base: 2rem;
  
  /* Increase the spacing rhythm */
  --a-space-unit: 1.25rem;
}

Dark Mode Support

Axiom01 includes automatic dark mode theming out of the box. All tokens adapt natively.

<!-- Force Light Mode -->
<html data-theme="light"></html>

<!-- Force Dark Mode -->
<html data-theme="dark"></html>

<!-- Inherit System Preference (Default) -->
<html></html>
