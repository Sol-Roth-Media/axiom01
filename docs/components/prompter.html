Stage Prompter & Lyrics HUD

Live performance teleprompter, stage lyrics prompter, and script runner with active line tracking, bar counts, and responsive portrait-friendly layout. Follows the Axiom01 specification ( \le 1$, semantic HTML5 tagging, zero utility classes).

Mobile & Portrait Adaptation

In mobile portrait aspect ratios, the prompter automatically reflows to a stacked vertical hierarchy: metadata summary on top, followed by full-width high-contrast lyrics stage, guaranteeing complete readability on handheld stage monitors and iPhones without horizontal clipping.
